# Rakesh Brahma - portfolio site

Plain HTML, CSS and a little JavaScript. No build step, no frameworks.

```
index.html      the whole page
media/          photos, clips and project recordings it loads
resume.pdf      add this file; the Résumé button in the nav opens it
```

To preview locally, open `index.html` in a browser.
To publish, upload this folder as-is to any static host (GitHub Pages, Netlify, Cloudflare Pages).
Keep `index.html` and `media/` side by side; the page loads media by relative path.
